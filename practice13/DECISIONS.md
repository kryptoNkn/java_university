# DECISIONS

1. для проверки пересечения интервалов используется формула startA < endB && startB < endA. оператор || здесь не подходит, так как из за него конфликт мог бы определяться даже между интервалами, которые не пересекаются. если конец одного интервала совпадает с началом другого, конфликт не возникает

2. ограничения по длительности и буферу вынесены в константы класса BookingService (MIN_MINUTES, MAX_HOURS, BUFFER_MINUTES). таким образом, все основные правила находятся в одном месте, а репозиторий отвечает только за работу с данными. если потребуется изменить условия, достаточно будет внести правки в одном классе
