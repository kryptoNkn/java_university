# Решения

1. для каждого тарифа доставки создан отдельный класс, который реализует DeliveryPolicy. в DeliveryService выбирается нужный тариф, после чего вызывается метод calculateCost. таким образом, расчёт стоимости стандартной, экспресс и экономичной доставки не находится в одном методе с большим количеством условий

2. значение 45 хранится только в классе EconomyPolicy в виде константы MIN_COST. это минимальная стоимость экономичной доставки по варианту 8. в остальных классах это значение не повторяется, поэтому при необходимости изменить минимальную стоимость достаточно будет внести изменения только в одном месте
