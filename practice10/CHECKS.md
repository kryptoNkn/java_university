2. Корректное типовое значение. STANDARD;12;4.5;12000. Вывод: STANDARD -> 230.00.
3. Верхняя граница веса включена. STANDARD;10;20;1000. Вывод: STANDARD -> 200.00.
4. Вес выше верхней границы. STANDARD;10;20.1;1000. Вывод: Строка 4: доставка этим способом невозможна.
5. Пустое поле. STANDARD;;4;1000. Вывод: Строка 5: Пустое поле.
6. Неверный формат. EXPRESS;abc;1;2000. Вывод: Строка 6: Неверный формат поля: расстояние.
7. Минимум варианта 8. ECONOMY;4;3;2000. Вывод: ECONOMY -> 45.00.
8. Минимум не срабатывает. ECONOMY;10;3;2000. Вывод: ECONOMY -> 80.00.

STANDARD -> 230.00
STANDARD -> 200.00

Строка 5: Пустое поле
Строка 6: Неверный формат поля: расстояние
ECONOMY -> 45.00
