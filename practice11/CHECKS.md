граничные проверки

прогон selfcheck завершился с результатом pass. ниже зафиксированы случаи из data/sample.csv и дополнительной временной выборки.

типовое значение и нижняя граница инн. строка 7701234567;alpha llc;office@alpha.ru содержит инн из 10 цифр. строка принята.

верхняя граница инн. строка 781234567890;beta inc;info@beta.com содержит инн из 12 цифр. строка принята.

неверный формат. строка 123;bad inn;bad@example.com и строка 7700000000;no mail;wrongmail отклонены. alpha и beta при этом сохранены: принято 2, ошибок 2.

верхняя граница названия, вариант 8. имя из 45 символов n и адрес ok@name.ru. строка принята, длина названия 45.

за пределом границы названия. имя из 46 символов n. строка отклонена, импорт следующих строк продолжен.

повтор инн. второй раз указан 7701234567. строка отклонена как дубликат, первая запись остаётся.

отсутствующий файл data/missing.csv. импорт завершается целиком, исключение не глотается.

по файлу data/sample.csv принято 2 записи (7701234567 и 781234567890) и отклонено 2 (короткий инн и email без @). по дополнительной выборке принято 2 и отклонено 2: дубликат инн и имя длиннее 45.
