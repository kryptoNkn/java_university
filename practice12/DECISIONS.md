# Решения

1. результат обработки собирается с помощью toList и groupingBy, без ручного добавления элементов во внешний список через forEach. исходная коллекция не изменяется, а отфильтрованные данные сохраняются в новой коллекции после завершения обработки потока

2. модификатор 45 находится в классе SalesAnalyticsService в константе SECONDARY_MODIFIER. при изменении вторичной сортировки достаточно внести правки только в этот класс, в методы byAmountThenSecondary и secondaryDistance. классы Sale и SelfCheck при этом остаются без изменений
